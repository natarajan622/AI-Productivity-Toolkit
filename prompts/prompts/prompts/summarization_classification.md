# Summarization and Classification Prompts

## 1. Text Summarization

### Objective
Convert long text into short and meaningful summaries.

### Prompt Template
Act as a professional summarization assistant.

Summarize the following text:
[INSERT TEXT]

Instructions:
- Use simple English.
- Identify the main points.
- Avoid unnecessary details.
- Present the result as bullet points.

## 2. Sentiment Classification

### Objective
Identify whether a text is Positive, Negative or Neutral.

### Prompt Template
Act as a sentiment analysis assistant.

Classify the following review:
[INSERT REVIEW]

Allowed categories:
- Positive
- Negative
- Neutral

Return only the category and a short reason.

## 3. Email Classification

### Objective
Classify emails based on their purpose.

### Categories
- Job Application
- Meeting Request
- Customer Support
- General Information

### Prompt Template
Classify the following email into one category:
[INSERT EMAIL]

Return the category and reason.

## 4. Expected Benefits
- Saves reading time.
- Organizes information.
- Improves productivity.
- Supports automated text processing.

## Learning Outcome
Understand how AI can summarize information and classify text.
