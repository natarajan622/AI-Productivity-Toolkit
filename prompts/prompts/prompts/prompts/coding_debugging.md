# AI-Assisted Coding and Debugging

## 1. Code Generation

### Objective
Generate code using clear natural language instructions.

### Prompt Template
Act as an experienced Python developer.

Write Python code for the following task:
[DESCRIBE YOUR TASK]

Requirements:
- Use simple Python.
- Add comments.
- Explain the code step by step.
- Include an example output.

## 2. Code Explanation

### Objective
Understand existing programming code.

### Prompt Template
Act as a Python programming tutor.

Explain the following code to a beginner:
[PASTE CODE]

Instructions:
- Explain each line.
- Identify important functions.
- Show the expected output.

## 3. Debugging

### Objective
Identify and fix programming errors.

### Prompt Template
Act as a Python debugging assistant.

Find the error in this code:
[PASTE CODE]

Error message:
[PASTE ERROR]

Requirements:
- Identify the cause.
- Provide corrected code.
- Explain the solution.
- Suggest how to prevent the error.

## 4. Testing

Ask AI to generate test cases for the corrected code.

## Benefits
- Faster code understanding.
- Easier error identification.
- Improved programming practice.
- Better debugging skills.

## Learning Outcome
Understand how AI can assist with coding, debugging and testing.
