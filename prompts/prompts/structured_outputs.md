# Structured AI Outputs

## Introduction
Structured output means asking AI to return information
in a predefined format such as JSON.

## Example 1: Student Information

Prompt:

Act as a data assistant.
Return the following student information in valid JSON.

Name: Arun
Course: BCA
Skill: Python

Expected Output:

{
  "name": "Arun",
  "course": "BCA",
  "skill": "Python"
}

## Example 2: Product Classification

Prompt:

Classify the following product into a category.
Return JSON with product and category fields.

Product: Laptop

Expected Output:

{
  "product": "Laptop",
  "category": "Electronics"
}

## Benefits
- Easy data processing
- Consistent output
- Better automation
- Easy integration with Python

## Learning Outcome
Understand how to generate structured JSON
responses using prompt engineering.
