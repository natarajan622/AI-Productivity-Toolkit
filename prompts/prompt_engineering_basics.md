# Prompt Engineering Basics

## 1. Zero-Shot Prompting

Zero-shot prompting means asking AI to perform a task
without providing examples.

Example:
Prompt: Classify this review as Positive or Negative:
"The product quality is excellent."

Expected Output: Positive

## 2. Few-Shot Prompting

Few-shot prompting means providing examples before
asking AI to perform a task.

Example:

Review: "Amazing product" -> Positive
Review: "Very poor quality" -> Negative

Review: "I love this product" -> ?

Expected Output: Positive

## 3. Role-Based Prompting

Give AI a specific role.

Example:
Act as an experienced Python teacher.
Explain variables to a beginner.

## 4. Context

Provide background information.

Example:
I am a BCA student learning Python.
Explain loops using simple examples.

## 5. Instructions

Clearly explain what AI should do.

Example:
Explain Python functions in five simple steps.

## 6. Constraints

Set limitations for the response.

Example:
Use simple English.
Keep the explanation under 100 words.
Include two examples.

## Learning Outcome

Understand the fundamentals of prompt engineering
and create reusable prompts for practical tasks.
